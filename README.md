# ☀️ Final Year Project

## Sobol-Halton Sequence Based Hippopotamus Optimization Algorithm for PV Systems Optimization

My final-year research explored improving photovoltaic system optimization using a modified **Hippopotamus Optimization Algorithm** combined with **Sobol and Halton low-discrepancy sequences**.

Key concepts explored:

- Photovoltaic system modelling
- Maximum Power Point Tracking — MPPT
- Metaheuristic optimization
- Hippopotamus Optimization Algorithm
- Sobol sequences
- Halton sequences
- Population initialization techniques
- Benchmark optimization functions
- MATLAB simulation
- Irradiance and module-temperature datasets

Conceptually:

```text
Solar Irradiance + Temperature
              │
              ▼
         PV System Model
              │
              ▼
    Sobol / Halton Initialization
              │
              ▼
 Hippopotamus Optimization Algorithm
              │
              ▼
        Optimal Operating Point
              │
              ▼
          Maximum PV Power
```
